Испанский – Русский

Медицинские ситуации для телефона: испанская фраза видна сразу; русский перевод появляется при наведении курсора или при нажатии на карточку. Звук доступен только для фраз пациента.

📱 Нажмите карточку, чтобы открыть перевод; нажмите ▶, чтобы услышать фразу пациента.
Материал для изучения. Фразы организованы по медицинским ситуациям. На телефоне коснитесь карточки, чтобы увидеть русский перевод. Кнопка ▶ появляется только рядом с фразами пациента.
