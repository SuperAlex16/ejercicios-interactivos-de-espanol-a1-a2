📌 Ir a + infinitivo — Futuro próximo

SUJETO + ir (presente) + a + INFINITIVO

Voy a cocinar esta noche. → (Я собираюсь готовить этим вечером.)

Vas a buscar trabajo mañana. → (Ты собираешься искать работу завтра.)

Va a salir el próximo viernes. → (Он/она собирается выйти в следующую пятницу.)

Ejercicio 3

Perífrasis verbales

empezar a · comenzar a · terminar de · acabar de · soler + inf · tener que + inf

Глагольные перифразы — это конструкции, состоящие из вспомогательного глагола + инфинитива. Выберите правильную перифразу для каждого предложения. Обратите внимание на значение каждой конструкции!
empezar a + inf
comenzar a + inf
Начинать что-то делать (начало действия)
Я начинаю готовить. → Empiezo a cocinar.
terminar de + inf
acabar de + inf
terminar de = заканчивать что-то делать  |  acabar de = только что что-то сделать (недавнее прошлое)
Acabo de llegar. = Я только что приехал.  |  Termino de cocinar a las 8. = Я заканчиваю готовить в 8.
soler + inf

tener que + inf
Нужно / надо что-то сделать (обязательство)
Tengo que estudiar. = Мне нужно учиться.
ponerse a + inf
Внезапно начать что-то делать
Se puso a llorar. = Он вдруг заплакал.

Ejercicio 4

Ser vs Estar

Dos verbos para «быть» — ¡muy diferentes!

В испанском языке есть два глагола «быть»: SER и ESTAR. Нажмите на правильный глагол для каждого предложения. Подсказка: SER — постоянные качества; ESTAR — временные состояния и местоположение.

📌 SER vs ESTAR — Regla fundamental

SER 🔵
✦ Identidad: Yo soy estudiante.
✦ Origen: Ella es de Madrid.
✦ Características permanentes: El azúcar es blanca.
✦ Profesión: Él es hombre de negocios.
✦ Materiales / descripción objetiva
ESTAR 🟢
✦ Estado temporal: Estoy cansada.
✦ Localización: El libro está en la mesa.
✦ Resultado de una acción: La tienda está cerrada.
✦ Estado de ánimo / salud
✦ Estar enfermo, estar cansado…

Ejercicio 5

Estar · Tener · Hay

Tres expresiones muy útiles — y muy diferentes

Три разные конструкции: ESTAR (местонахождение / состояние), TENER (иметь / обладать), HAY (существование — «есть», «имеется»). Выберите правильный вариант для каждого предложения.

📌 ESTAR vs TENER vs HAY

ESTAR 🟢
Localización:
El libro está en la mesa.

Estado:
Estoy cansado.
TENER 🟠
Posesión:
Tengo una sartén.

Sensación física:
Tengo hambre.
HAY 🟡
Existencia (invariable):
Hay un mercado cerca.
Hay muchas personas.

= есть / имеется / существует
⚠️ Atención: HAY es siempre invariable (no cambia con singular/plural).
«Hay un mercado» / «Hay muchos mercados» → siempre hay.
